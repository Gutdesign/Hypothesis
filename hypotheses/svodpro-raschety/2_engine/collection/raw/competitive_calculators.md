# Конкурентный анализ онлайн-калькуляторов для проектировщиков РФ по ГОСТ/СП: лифты, эвакуация, общепит, бассейны

## Краткое резюме (Executive Summary)

- **Доминирующая платформа для лифтов по СП 267 — КРУПТ, но кодовая база устарела**: бесплатные калькуляторы `tools.krupt.ru` (три сценария: односторонний, двусторонний пассажиропоток и высотные здания выше 75 м) считают по **ГОСТ Р 52941-2008 и СП 267.1325800.2016**, но не по действующему **ГОСТ Р 55964-2014** — это юридический и конкурентный риск. → Архитекторам стоит явно отслеживать редакцию норматива, прежде чем доверять результату.
- **Международные производители (Otis, KONE) ушли или локализованы без онлайн-инструмента для СП**: `otis.com/ru/ru` редиректит на Казахстан, `kone.ru` не имеет русскоязычного калькулятора по СП — единственная международная бесплатная утилита **KONE Elevator/Escalator Planner** (BIM) таргетирует американский рынок ([18]). → В нише российского рынка нет «manufacturer sales tool» — окно возможностей для отечественных производителей.
- **Российские производители лифтов предлагают не расчёт, а конфигуратор**: `web.kmzlift.ru` (КМЗ) даёт выбор серии «СИРИУС» по грузоподъёмности/скорости, но не пассажиропоток ([36]); у ЩЛЗ и Могилёвлифтмаш онлайн-инструментария для расчёта числа лифтов не обнаружено. → Это означает, что проектировщик вынужден комбинировать «нормативный калькулятор» + каталог: процесс не автоматизирован.
- **Условные блюда — самая «заполненная» ниша**: три конкурирующих калькулятора ([31], [89], [88]) реализуют формулу по **СП 30.13330.2020/2022**, и они бесплатны. → Ниша насыщена; монетизировать можно только привязкой к оборудованию (линии раздачи, посуда, мебель).
- **Эвакуация — самая слабая ниша**: нет ни одного полноценного бесплатного онлайн-калькулятора по **СП 1.13130.2009**; коммерческие услуги (Evaplan.by, [14], [54]), а единственная десктоп-программа **GreenLine+** распространяется с 30-дневным тестом ([50]). → Явный GAP; свободная ниша для AI/онлайн-сервиса.
- **Водоподготовка бассейна — критический GAP**: найдены только объёмные калькуляторы ([2]) и калькуляторы гидравлики насосов ([3]), но **ни одного онлайн-инструмента, реализующего методику СП/СанПиН для подбора фильтра, циркуляционного расхода, обеззараживания**. → Предложение по созданию специализированного калькулятора «фильтр + насос + хлоратор по СП».
- **SvodPro (svodpro.ru) — навигатор по нормам, а не калькулятор**: AI-ассистент по СП/ГОСТ с платной подпиской ([21]), не реализует численные расчёты напрямую; аналоги ([22], [25], Народ.РУ) — наборы разрозненных калькуляторов без AI. → SvodPro выполняет смежную роль и может использовать API расчётных модулей.
- **Только КРУПТ покрывает более одной темы нормативных расчётов**: теплосопротивление, МГН, лифты, калорифер, вентиляция горячего цеха, водопотребление ([41]) — остальные сервисы либо узкие, либо коммерческие. → КРУПТ фактически занимает нишу «инженерный швейцарский нож» для проектировщика.

## 1. Вертикальный транспорт: ГОСТ Р 55964 и СП 267.1325800

### 1.1 Что предлагает КРУПТ (tools.krupt.ru)

КРУПТ — архитектурная компания, выпустившая набор бесплатных веб-инструментов на базе действующих российских норм. Каталог `tools.krupt.ru` делится на разделы «Архитектурно-строительные решения» и «Инженерные сети», и содержит **три расчёта лифтов**:

| URL | Назначение | Нормативная база |
|---|---|---|
| `tools.krupt.ru/oneDirectTrafficLiftsCalculation` | Односторонний пассажиропоток | ГОСТ Р 52941-2008 |
| `tools.krupt.ru/doubleDirectTrafficLiftsCalculation` | Двусторонний пассажиропоток | ГОСТ Р 52941-2008 |
| `tools.krupt.ru/highRiseBuildingsTrafficLiftsCalculation` | Высотные здания > 75 м | СП 267.1325800.2016 (приложения Д.1, Д.2, Д.3, Д.7.3, Д.8) |

**Функциональность**: калькулятор выдаёт количество и комплект (грузоподъёмность 320–2500 кг, скорость 0,4–6 м/с, дополнительные лифты по приложению Д), провозную способность и интервал движения. Расчёт полностью нормативный, **без привязки к каталогу конкретного производителя** ([28]).

**Цена**: бесплатно, без регистрации.

**Позиционирование**: полноценная инженерная платформа, а не «sales tool». Один калькулятор энергоэффективности, теплосопротивления неоднородностей, МГН и каменных стен, МГН-площадок и т. д. — тоже на той же странице ([41]).

**Insight (Observation -> Mechanism -> Implication -> Recommendation)**:
- *Механизм*: КРУПТ — это проектная компания, размещающая инструменты для самостоятельных проверок расчётов заказчика (то есть lead-magnet), а не калькулятор для конечной спецификации оборудования.
- *Implication*: пользователь получит корректные «инвариантные» числа (сколько лифтов какой грузоподъёмности), но должен сам выбирать конкретную модель в каталоге завода.
- *Recommendation*: для проектировщика — рабочий инструмент предварительной компоновки, но не заменяющий спецификацию по продукту.

### 1.2 Кодовая база КРУПТ: риск устаревших нормативов

В нормативных зданиях «до 75 м» КРУПТ считает по **ГОСТ Р 52941-2008**, тогда как актуальный на 2024–2026 годы — **ГОСТ Р 55964-2014 «Лифты. Методика расчёта»**. Это не точно ошибка методики, но означает, что калькулятор может расходиться с параметрами, которые засчитывает экспертиза сегодня. Риск усиливается тем, что **СП 267.1325800.2016** и **ГОСТ Р 55964-2014** используют разные подходы к интервалу и провозной способности. → Проектировщик, использующий КРУПТ, должен явно фиксировать редакцию норматива в пояснительной записке.

### 1.3 Производители лифтов и их онлайн-инструменты

| Производитель | Онлайн-инструмент | Тип | Привязка к СП 267 / ГОСТ 55964 |
|---|---|---|---|
| Otis (США) | `otis.com/ru/ru` — редирект на Казахстан | Сайт фактически недоступен для РФ | нет |
| KONE (Финляндия) | `kone.ru` — без русскоязычного калькулятора; **KONE Elevator / Escalator Planner** на `kone.us` — бесплатный BIM-плагин | Manufacturer sales tool (мировой) | нет (не российские нормы) |
| КМЗ (Карачаровский механический завод) | `web.kmzlift.ru` — **конфигуратор серии «СИРИУС»** | Manufacturer sales tool | частичная (грузоподъёмность 400–1275 кг, скорость 0,71–1,6 м/с) |
| Щербинский лифтостроительный завод (ЩЛЗ) | `shlz.ru` — корпоративный сайт без онлайн-калькулятора | информационный | нет |
| Могилёвлифтмаш | `liftmach.by` — каталог | информационный | нет |

**Insight**:
- *Otis*: уход с российского рынка означает, что для архитекторов РФ нет привязанного к федеральным нормам онлайн-инструмента от глобальной компании. → Свободное окно для отечественного разработчика (например, AI-связка «СП + каталог ШЛЗ/КМЗ/Могилёв»).
- *KONE*: бесплатный BIM Planner — это скорее инструмент архитектора-проектировщика для глобальных проектов; ru-локализации с привязкой к СП не существует.
- *КМЗ*: конфигуратор помогает выбрать конкретную модель, но **не рассчитывает** число лифтов — пользователь должен сам знать пассажиропоток ([36], Ведомости/В100видов).

### 1.4 Gaps для лифтов

- Отсутствует онлайн-инструмент, реализующий **ГОСТ Р 55964-2014** явно и бесплатно.
- Нет ни одного manufacturer sales tool, который выполнял бы пассажиропоток по СП 267 и сразу предлагал модель из каталога завода.

## 2. Пропускная способность путей эвакуации (СП 1.13130.2009, ГОСТ 12.1.004)

### 2.1 Картина рынка

Поиск возвращает преимущественно **услуги**, а не онлайн-калькуляторы:

| Площадка | Что даёт | Цена |
|---|---|---|
| [13] | Расчёт путей и времени эвакуации по ГОСТ 12.1.004, СН 2.02.01-2019 (Беларусь, но методология совместима) | платная услуга |
| [14] | Расчёт пожарных рисков и времени эвакуации + разработка СТУ | платная услуга |
| [54] | Расчёт времени эвакуации в Москве | платная услуга |
| [75] | Расчёт путей и времени эвакуации людей при пожаре | платная услуга |
| **GreenLine+** ([50]) | Десктоп-модуль для расчёта времени эвакуации | 30-дневный тест, потом лицензия |

Найденный «Калькулятор коэффициента Cv» на [12] — это **инструмент для подбора клапанов**, а не для людей; в research-выдаче оказался ложноположительным.

### 2.2 Insight

- **Gap очевиден**: ни одного бесплатного онлайн-симулятора движения людских потоков под СП 1.13130.2009 не найдено.
- *Механизм*: методика требует геометрии путей, плотности потоков и групп мобильности — это сложнее, чем линейный расчёт лифтов; внятных SaaS-сервисов ещё не появилось.
- *Implication*: проектировщик либо платит ~10–30 тыс. руб. за услугу, либо считает «руками» в Excel/Word.
- *Recommendation*: ниша для AI-продукта, который принимает план этажа и возвращает время эвакуации и узкие места — аналог зарубежных Pathfinder / Fenix+.

## 3. Условные блюда: расчёт по СП 30.13330.2020 / СП 118.13330

### 3.1 Что реально работает

Три онлайн-калькулятора реализуют формулу количества условных блюд (по числу посадочных мест и удельному показателю m):

| Источник | URL | Содержание | Цена |
|---|---|---|---|
| ViVBim | [31] | Многошаговый калькулятор: тип заведения (ресторан, столовая, студенческая, бар), норма площади, число мест, нормативный m, «блюд в час», пересчёт через СП 30.13330.2020 | бесплатно |
| xTechOnline | [89] | «Профессиональный расчёт количества условных блюд по формуле СП 30.13330.2020» | бесплатно |
| Центр ПСС | [88] | «Расчёт количества условных блюд на предприятиях общественного питания по СП, реализуемых за один рабочий день» | бесплатно |

Прикладные (не проектировочные) кулинарные калькуляторы — [10], [7] — решают себестоимость и граммовки, а не количество блюд по нормативу.

### 3.2 Insight

- *Механизм*: проектировщик общепита должен рассчитать число посадочных мест → число блюд в час → суточное количество → технологическое оборудование. Три конкурирующих калькулятора закрывают первый шаг.
- *Implication*: ниша насыщена по **числу** и качеству предложений; добавленная стоимость возникает только при привязке к каталогу оборудования (пароконвектоматы, фритюрницы, линии раздачи).
- *Recommendation*: монетизировать имеет смысл только через рекомендацию конкретных моделей оборудования — а не через саму формулу.

## 4. Водоподготовка бассейна (СП, СанПиН 2.1.2.1188)

### 4.1 Что найдено

| Площадка | URL | Функциональность | Цена |
|---|---|---|---|
| Аквабас | [2] | Объём воды по форме (прямоугольник, круг, овал), переход к подбору оборудования по результату | бесплатно |
| Еврострой Инжиниринг | [4] | Калькулятор стоимости бассейна (длина, ширина, глубина, тип) | бесплатно, но это коммерческий расчёт |
| SLPumps | [3] | Мощность насоса по расходу / напору; общеинженерный | бесплатно |
| МСМ-Тепло | [59] | Подбор теплообменника для бассейна | платная услуга / расчёт под заказ |
| Aquapolis | [80] | Каталог фильтров + описание, без онлайн-расчёта | информационно |

### 4.2 Критический GAP

**Не найдено ни одного онлайн-инструмента**, который выдавал бы:
- расход циркуляции по нормам (6 часов на оборот для общественного бассейна по СанПиН);
- скорость фильтрации (обычно ≤ 50 м/ч для песочных фильтров);
- требуемую массу засыпки;
- дозировку хлора/коагулянта по объёму и температуре воды.

Всё это инженеры делают в Excel или заказывают у поставщика услуги. Это явная **незакрытая ниша** для профильного продукта.

## 5. SvodPro и аналоги: AI-ассистенты по нормам

### 5.1 SvodPro ([21])

- **Позиционирование**: «PRO-поиск по строительным нормам» — AI-ассистент для навигации по СП/ГОСТ.
- **Слоган**: «SvodPro — ваш ИИ-ассистент в работе с нормативами. Находите точные ссылки на СП и ГОСТ за секунды, защищайте решения перед экспертизой и проверяйте проекты на соответствие нормам».
- **Что умеет**: цитировать пункты СП/ГОСТ, отвечать на нормативные вопросы. **Не выполняет численных расчётов** и не предлагает калькуляторов.
- **Бизнес-модель**: тарифная сетка (`svodpro.ru/pricing`) — есть бесплатный вход.

### 5.2 Аналоги

| Сервис | URL | Что даёт | Функционал расчётов |
|---|---|---|---|
| Стройкалькулятор.РУ | [22] | Набор калькуляторов (стены, фундаменты, кровля) | изолированные калькуляторы, без AI |
| Технониколь | [25] | Калькуляторы производителя стройматериалов | ограничены продуктами TN |
| Millars Народ.РУ | [24] | Статичный набор таблиц | без AI |

### 5.3 Insight

- *Механизм*: AI-ассистент «по нормам» работает с поиском и комментариями СП/ГОСТ, но не решает инженерные уравнения. **SvodPro не конкурирует с КРУПТ, ViVBim и т. д. — он о другой ступени**.
- *Implication*: естественный путь развития для SvodPro — прикрутить API/iframe расчётных модулей других сервисов (включая КРУПТ) и вызывать их из ответов чат-бота («Посчитайте лифты для 25-этажного МКД» → вызов КРУПТ → возврат числа лифтов + ссылка на СП 267 + цитата пункта).
- *Recommendation*: партнёрство SvodPro ↔ КРУПТ — взаимовыгодно; обоим усилит LTV.

## 7. Сравнительный и сквозной анализ (Synthesis)

### 7.1 Сравнение по 4 измерениям

| Измерение | КРУПТ | ViVBim | Evaplan / GreenLine+ | SvodPro | KMZ |
|---|---|---|---|---|---|
| **Механизм ценности** | Нормативный калькулятор + лидогенерация | Нишевая ERP-калькуляция | Услуга / лицензия (SaaS отсутствует) | AI-навигация по СП | Sales tool (конфигуратор) |
| **Охват норм** | Широкий (тепло, лифты, МГН, вентиляция) | Один домен | Один домен | Все СП/ГОСТ | Каталог серии |
| **Привязка к оборудованию** | нет | нет | нет | нет | да (только серия) |
| **Цена для пользователя** | бесплатно | бесплатно | платно / freemium (trial) | freemium | бесплатно как lead magnet |

### 7.2 Скрытые противоречия

- **КРУПТ vs ГОСТ Р 55964**: КРУПТ применяет **ГОСТ Р 52941-2008**, тогда как действующий — **ГОСТ Р 55964-2014**. Позиция «считает по нормам» формально не точна — это риск для экспертизы.
- **KONE vs РФ**: KONE глобально продвигает BIM Elevator Planner бесплатно, но русскоязычной версии с привязкой к СП нет — **KONE де-факто не инвестирует в онлайн-инструмент для РФ**.
- **SvodPro vs расчётные сервисы**: SvodPro фактически создаёт рынок «нормативного copilot», но сам не считает — иначе говоря, это «нормативный гугл», а не «калькулятор». Это разные ниши, но они коллокируются в одном поиске проектировщика.
- **Otis ушёл, КМЗ расширяется**: на сайте KMZ указано «производственная мощность — лифтов в год» с быстрым SLA («лифт за 10 дней»). → Окно возможностей для КМЗ сделать собственный нормативный калькулятор «для проектировщика».

### 7.3 Почти все ниши делятся на 3 типа

1. **Нормативный калькулятор (КРУПТ, ViVBim)** — вычисляет по формуле СП без каталога. Цена: бесплатно, монетизация через лид.
2. **Услуга / расчёт под ключ (Evaplan, ВДПО, МСМ-Тепло)** — дорого, но берёт на себя ответственность.
3. **Sales tool (КМЗ «СИРИУС»)** — выбирает модель, но не выполняет нормативный расчёт потока.

**Ни один из существующих сервисов не объединяет все три роли** — **это главный стратегический разрыв ниши**.
