# knowledge/

Общая база знаний: сюда пишут и отсюда читают и гипотезы, и исследования ландшафта. Правила — в `CLAUDE.md`, раздел «Knowledge base».

| Что | Где |
|-----|-----|
| Этапы цепочки (S0–S9, X-*) и соответствие международным планам работ | `value_chain.md` |
| Реестр компаний (источник правды) | `companies/registry.csv` |
| Реестр компаний (читаемый вид, генерируется) | `companies/registry.md` |
| Рыночные данные (темпы роста и др.) | `markets/` |
| Болевые точки с оценкой доказательств | `pains.md` |

Реестр: разделитель `;`, кодировка UTF-8 с BOM (чтобы Excel с русской локалью открывал без перекодирования).
Команды: `python scripts/registry.py build` — пересобрать `registry.md`; `python scripts/registry.py merge updates.csv` — влить обновления по `id`; `python scripts/registry.py stats` — покрытие этапов и заполненность полей.

Правила данных: факт без ссылки на источник не записывается (пишем `н/д`); классификация по описанию основателя помечается `оценка по описанию`; поле `данные_проверены` отражает, сверены ли данные с первоисточником.
