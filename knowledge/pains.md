# Болевые точки

Пополняется по мере исследований ландшафта и гипотез. Шкала доказательств: A — независимое подтверждение (≥2 независимых источника со стороны покупателя либо официальная статистика); B — один источник со стороны покупателя или первичный источник (отзыв пользователя, решение органа власти, данные регулятора); C — заявление вендора, пресс-релиз, один вторичный источник; D — вывод модели без источника либо источник без результатов (например, приглашение к опросу).
