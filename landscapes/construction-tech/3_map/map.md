## Ограничения карты

1. **Перекос списка:** большинство строк — стартапы, привлёкшие внешние деньги; США — 47 из 116.
2. **Качество данных:** 105 строк из 116 — «частично проверено» (агрегаторы и пресс-релизы), подтверждены отчётностью только Procore и Autodesk (по результатам поиска, сам документ не открывался). Суммы привлечённых денег и численность расходятся между агрегаторами в десятки процентов.
3. **Выручка:** публично известна только у компаний с отчётностью (Procore, Autodesk, Bentley, Trimble, Nemetschek, Hexagon) и у нескольких зрелых частных компаний с диапазонами. У стартапов — только оценки агрегатора Latka, которые я помечал отдельно: это слабые оценки (в одном случае HqO — расходятся с масштабом привлечённых денег).
4. **Этапы:** классификация сделана по одной строке описания основателя и уточнена по прессе для части компаний; пометка `оценка по описанию` есть не у каждой строки — по умолчанию считать все этапы оценкой.
5. **Нет данных о спросе:** нет данных о ценах, оттоке, числе клиентов (кроме заявлений компаний), расходах отрасли на ПО.
6. **Не найдена:** Standard Access (поиск по названию ничего не дал); у TerraFirma и GreenLite сайт не подтверждён.
